Clínica Veterinaria - Base de Datos SQL:

Proyecto de modelamiento y gestión de base de datos para una clínica veterinaria.

Descripción:

Este proyecto contiene la estructura y gestión de datos para administrar:
- Dueños
- Mascotas
- Atenciones veterinarias

Estructura del proyecto:

- `ClinicaVeterinaria_CreaciónTablas.sql` → Script de creación de tablas
- `ClinicaVeterinaria_InserciónDatos.sql` → Inserción de datos de prueba
- `ClinicaVeterinaria_Consultas.sql` → Consultas y procedimientos almacenados

Tecnologías utilizadas:

- SQL
- MySQL
